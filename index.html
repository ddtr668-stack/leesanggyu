구글 드라이브 완전 자동 저장 스크립트 1분 설정법 보기

1. 구글 드라이브 폴더에서 새로 만들기 ➔ 더보기 ➔ Google Apps Script를 클릭합니다.

2. 아래 코드를 복사해서 붙여넣고 상단의 [배포] ➔ [새 배포] ➔ 유형: 웹 앱 (액세스: 모든 사용자)으로 배포합니다.

function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var folder = DriveApp.getFolderById("1_Z2iV8nVzn3Qf3-jSFv4altgJNEaOlah");
  if (data.receiptBase64) {
    var split = data.receiptBase64.split(",");
    var contentType = split[0].split(";")[0].replace("data:", "");
    var decoded = Utilities.base64Decode(split[1]);
    var blob = Utilities.newBlob(decoded, contentType, data.date + "_" + data.merchant + "_영수증.png");
    folder.createFile(blob);
  }
  return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON);
}

3. 생성된 웹앱 URL을 위 입력칸에 넣고 [설정 저장]을 누르면 완료됩니다!
