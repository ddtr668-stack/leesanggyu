// 꼬여있는 스프레드시트 열을 완벽하게 제자리로 정렬하는 정제 함수 function normalizeExpense(item, index) { // 1. 이미지 분리 판별 let rawImage1 = item.imageUrl || ''; let rawImage2 = item.statementUrl || ''; let imageUrl = ''; // 영수증 사진 let statementUrl = ''; // 거래명세서 사진 // 만약 1개의 사진만 있고, 현재 영수증 칸에 명세서가 들어간 경우 -> 명세서 칸으로 이동 if (rawImage1 && !rawImage2) { statementUrl = rawImage1; // 현재 등록된 사진들은 모두 거래명세서 } else { imageUrl = rawImage1; statementUrl = rawImage2; } // 2. 결제 금액 복구 (결제자 열에 들어간 310200, 38500 등 숫자 추출) let parsedAmount = 0; const amountCandidates = [item.user, item.amount, item.purpose]; for (let cand of amountCandidates) { if (cand !== undefined && cand !== null && cand !== '') { let num = 0; if (typeof cand === 'number') num = cand; else if (typeof cand === 'string' && !cand.startsWith('http')) { num = Number(cand.replace(/[^0-9.-]+/g, '')) || 0; } if (num >= 100) { // 정상 금액 감지 parsedAmount = num; break; } } } // 3. 계정과목 복구 (현재 '사용처' 칸에 들어가 있는 기타비용, 복리후생비 등 추출) const standardCats = [...new Set([...customCategories, ...BASE_CATEGORIES, '기타비용', '식대'])]; let category = '기타'; const catCandidates = [item.merchant, item.category]; for (let cand of catCandidates) { if (typeof cand === 'string') { const match = standardCats.find(c => cand.includes(c)); if (match) { category = match; break; } } } // 4. 사용처 & 이용 목적 분리 (현재 '계정과목' 칸에 들어간 "서광레미콘 EHS 자재 부품 구매" 등) let combinedText = ''; if (typeof item.category === 'string' && item.category !== category) { combinedText = item.category; } else if (typeof item.purpose === 'string' && item.purpose !== '-') { combinedText = item.purpose; } else if (typeof item.merchant === 'string' && item.merchant !== category) { combinedText = item.merchant; } let merchant = ''; let purpose = ''; if (combinedText) { const parts = combinedText.trim().split(/\s+/); // 첫 번째 단어를 가맹점 상호로 분리 (예: '서광레미콘', '육송') merchant = parts[0]; // 나머지 전체를 이용 목적/품목으로 분리 (예: 'EHS 자재 부품 구매', '중식 식대(백반 5인분)') purpose = parts.slice(1).join(' ') || combinedText; } else { merchant = item.merchant || '미입력'; purpose = item.purpose || '-'; } // 5. 결제자 (숫자가 아닌 순수 이름인 경우만 유지) let user = ''; if (typeof item.user === 'string' && isNaN(Number(item.user.replace(/,/g, '')))) { user = item.user; } // 6. 사용일자 검증 let date = item.date || ''; if (typeof date === 'string' && date.length > 10) date = date.substring(0, 10); if (!/^\d{4}-\d{2}-\d{2}$/.test(date)) { date = new Date().toISOString().substring(0, 10); } return { id: String(item.id || ('exp_' + index + '_' + Date.now())), date: date, merchant: merchant, amount: parsedAmount, category: category, user: user || '-', purpose: purpose, imageUrl: imageUrl, statementUrl: statementUrl }; }
